# Commit hash map

The commit messages of the first 54 commits after the initial public push carried a `Co-Authored-By` trailer. They were rewritten before publication so
that the repository shows a single author. **Every rewritten commit has exactly the same tree (file contents) as before**, checked pairwise; only the
message trailer and therefore the commit hashes changed.

The frozen manifests (`docs/research/*/manifest.json`), `docs/preregistration/D107-availability-implementation.md` and the technical manual cite the
old short hashes, and those documents are not edited (frozen). Look up an old hash here to find the commit it became. The tags (`research-v1`,
`replay-r1`, `sparse-r2`, `audit-r6`, `audit-r7`, `inventory-r5`, `fa-r5`, `observation-r3r4`, `stage2-r7`) were moved to the rewritten commits.
